Contrôles d'édition

⠿ Poignée — glisser pour réorganiser l'ordre des widgets. Le défilement de la page est neutralisé pendant le glissement.
Œil — masquer / afficher. Un widget masqué reste listé ici (grisé + « Masqué ») → toujours réaffichable. Présent sur tous les widgets (Streak compris).
Taille — bascule normale (carte) ↔ compacte (une ligne : titre + valeur clé).
✓ Terminé — sort du mode édition. Chaque changement est persisté aussitôt (user_settings.dashboard_layout) et synchronisé.
Piliers inactifs : les widgets d'un pilier désactivé n'apparaissent ni en vue ni en édition (réapparaissent si le pilier est réactivé).
Nouveau widget ajouté plus tard : apparaît automatiquement en fin de liste, visible, taille normale (jamais perdu).

Maquette statique — les couleurs/typos suivent le thème réel de l'app (sombre). Les polices exactes (Bricolage Grotesque / Hanken Grotesk / Space Mono) peuvent être approximées ici selon le rendu du navigateur.
