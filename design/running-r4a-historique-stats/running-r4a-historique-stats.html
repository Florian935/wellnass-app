Décisions (rappel)

  • Un seul écran « Historique & progression » (onglet Course) : stats + courbe + liste. Lecture seule sur runs.
  • Stats par période calendaire : semaine (lun→dim), mois, depuis le début. Distance / temps / nombre de courses (via useUnits).
  • Courbe d'allure globale (pas par type — les courses n'ont pas de type) sur fenêtres glissantes 30 / 90 j + tendance. ⚠️ Allure basse = rapide → une ligne descendante = progrès (libellé de tendance pour lever l'ambiguïté). Réutilise ProgressLineChart.
  • Liste chronologique (terminées, plus récentes d'abord) → tap = détail existant (run/summary?id=, carte + splits). Pas de filtre (type/programme indisponibles).
  • Différés : export GPX (5.33), records d'allure + maj réf (R4b), dénivelé (5.32, altitude non captée), découpage par type.
  • Polices : stand-ins système ici ; en app = Bricolage / Hanken / Space Mono. Courbe = illustrative.
