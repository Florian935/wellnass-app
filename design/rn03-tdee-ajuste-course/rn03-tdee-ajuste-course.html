RN-03 — Ajustement auto du TDEE selon le volume de course

Widget conditionnel du dashboard (Tier 2, ADR-007), gardé par running et nutrition — un insight, pas une alerte de sécurité (ton neutre, tuile course plutôt qu'ambre).

✅ Décisions D1-D5 arbitrées par Florian le 04/08/2026, code livré (TDD) le même jour — cette maquette reflète les règles telles qu'implémentées.

Le trou que ça comble : RN-02 ajuste le jour, RN-03 ajuste le socle

nutrition_profiles.activity_level est choisi une fois à l'onboarding et ne bouge plus jamais tout seul — même si le volume de course change durablement pendant des mois. RN-02 (livrée) compense un jour de séance ; RN-03 propose de corriger le socle utilisé tous les jours, course ou pas.

fréquence = jours distincts avec course terminée sur les 14 derniers jours calendaires
palier suggéré = fréquence convertie en moyenne j/semaine, mappée aux bornes de la spec §2.2
suggestion émise seulement si palier suggéré ≠ palier déclaré

2 · Quand le widget reste masqué

Palier déjà cohérent (R3)

3 courses/2 semaines, profil déjà « Modérément actif » → rien à signaler, pas un état « à jour » affiché : le widget disparaît comme n'importe quel widget conditionnel.

Course ou nutrition inactif

Sans les deux piliers, ni la fréquence ni le niveau déclaré ne sont disponibles — le widget ne s'affiche jamais, quel que soit l'historique.

Plafond « Très actif » (D4)

7 courses/semaine sur toute la fenêtre : suggestion plafonnée à « Très actif », jamais « Extrêmement actif » — aucun seuil sourcé pour ce palier dans la spec §2.2.

Dans les 3 cas ci-dessus : rien à cet endroit du dashboard.

3 · Coexistence avec RN-02 (bonus du jour)

RN-02 (dayCalorieBonus) et RN-03 (cette US) répondent à deux questions différentes, sur deux échelles différentes : RN-02 = « combien manger aujourd'hui, jour de course ? » (déjà livré, inchangé) · RN-03 = « mon niveau déclaré, valable tous les jours y compris de repos, reflète-t-il encore mes deux dernières semaines ? ». Aucune donnée ni fonction partagée entre les deux au-delà de la lecture de runs.
