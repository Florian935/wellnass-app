Décisions de la maquette (MVP)

  • Séance du jour (H1) — prochaine séance du programme muscu actif (« Séance N · nom »), pas de planning hebdo. CTA Démarrer ; Reprendre si une séance est en cours.
  • Régularité / streak (H2·H3) — jour actif = 1 séance muscu ou course running ou ≥ 1 repas nutrition. Pastille pleine = jour actif, contour = aujourd'hui. Pas de « repos neutre » au MVP.
  • Poids (H4) — affiché si le pilier nutrition est actif. Valeur + tendance 7 j via useUnits() → kg ou lb selon le réglage.
  • Piliers — chaque carte n'apparaît que si son pilier est actif (max 4 blocs). Temps réel : les cartes se mettent à jour en direct (terminer une séance, ajouter un repas…).
  • i18n FR + EN — aucune chaîne en dur ; le message « le journal arrive bientôt » est supprimé.
  • Polices : stand-ins système ici ; en app = Bricolage Grotesque (titres/chiffres display), Hanken Grotesk (corps), Space Mono (nombres).
