Décisions (rappel)

  • Réutilise l'infra programmes muscu : tables programs (pillar='running') / sessions / program_translations (nom + résumé bilingues). Séances running = 3 colonnes ajoutées à sessions (type + cible distance/durée).
  • Séance = type + cible (distance en km ou durée en min). L'allure cible est affichée (dérivée du type + profil R3a via sessionTargetPace, en min/km ou min/mi), jamais stockée.
  • Types de programme : endurance, fractionné, sortie longue, récupération (course libre exclue).
  • Un seul programme running actif à la fois. Duplication possible. État « pas de profil » → invite à définir l'allure de réf.
  • Différé : structure de blocs du fractionné (6×400 m…), bibliothèque + filtres + seed (R3b-ii), planning (R3c), démarrer une course depuis une séance.
  • Polices : stand-ins système ici ; en app = Bricolage / Hanken / Space Mono.
