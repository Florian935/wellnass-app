MN-04 — Macros ajustées jours muscu (glucides péri-séance)

Pas un nouveau widget — correction du calcul des cibles macro déjà affichées sur NutritionSummaryCard (dashboard) et l'écran Nutrition. Le trou était déjà documenté dans un commentaire du code : « les macros cibles restent calées sur l'objectif de base (bonus non ventilé) ».

✅ Décision D1 arbitrée par Florian le 04/08/2026 (100 % du bonus vers les glucides), code livré le même jour — cette maquette reflète la règle telle qu'implémentée.

Le trou, en image — jour de séance muscu, bonus +400 kcal

L'anneau de calories (non montré ici, inchangé) affiche déjà l'objectif effectif (base + bonus). Les 3 barres macro juste en dessous, elles, ne bougent pas avec lui aujourd'hui.

Avant — bonus invisible
Objectif affiché en haut : 2 400 kcal (2 000 base + 400 bonus séance)
Protéines150 g cible
Glucides225 g cible
Lipides56 g cible
150×4 + 225×4 + 56×9 = 2 004 kcal — ne totalise pas les 2 400 affichés en haut. Les 400 kcal de bonus n'apparaissent nulle part dans le détail.
Après — bonus vers les glucides
Objectif affiché en haut : 2 400 kcal (inchangé)
Protéines150 g cible
Glucides325 g cible (+100)
Lipides56 g cible
150×4 + 325×4 + 56×9 = 2 404 kcal — cohérent avec les 2 400 affichés (arrondis). Les glucides absorbent exactement le bonus (400 kcal ÷ 4 = 100 g).

Jour de repos — rien ne change (règle R4)

effectiveTarget === targetBase (aucun bonus) → trainingDayMacroGrams retourne exactement le même résultat que le calcul actuel. Cette US ne modifie **aucun** affichage hors jour de séance/course avec bonus.

Les règles

R1 — 100 % du bonus vers les glucides (D1) Pas de répartition avec les protéines — MN-06 couvre déjà une cible protéines indépendante, en g/kg. Scinder le bonus inventerait un ratio non sourcé.
R2 — Mode manuel toujours prioritaire Si l'utilisateur a fixé ses macros à la main, le bonus reste invisible pour lui — comportement inchangé, aucune recombinaison automatique.
R3 — Agnostique de l'origine du bonus Forfait fixe (jour muscu) ou dépense réelle de course (mode auto, RN-02) : même règle, aucune distinction par pilier.
R4 — Jour sans bonus = comportement inchangé Le calcul actuel n'est pas remplacé, seulement complété pour le cas où un bonus existe.
