Drag & drop en grille + 3 formes par module

Correctif des retours : (1) en édition, on attrape un module et on le dépose n'importe où dans la grille 2 colonnes — deux petits carrés se posent côte à côte ; (2) chaque module a un rendu propre à chacune de ses 3 formes (petit carré ½ largeur, rectangle pleine largeur, grand carré pleine largeur), qui remplit vraiment la surface. Rendu dans le design system de l'app.

AÉdition — glisser-déposer dans la grille

Appui long sur un module → il se soulève (fantôme). On le promène sur la grille ; une barre d'insertion montre où il atterrira. En le lâchant entre deux petits carrés, il se pose à côté d'eux. Les contrôles (œil = masquer, ◻ = changer de forme) passent en pastilles de coin pour tenir même sur un petit carré.

BLes 3 formes, module par module

Décisions & implémentation

  • Drag & drop en grille (remplace le tri 1 colonne) : appui long → fantôme suivant le doigt, barre d'insertion, dépôt libre. Deux petits carrés consécutifs = même ligne. Fondé sur react-native-reanimated + gesture-handler (hit-test des positions mesurées → index d'insertion, réordonnancement + re-pavage).
  • Contrôles d'édition en pastilles de coin (œil masquer + ◻ forme) pour tenir sur un petit carré ; l'ancienne barre de contrôles disparaît.
  • 3 formes par module : small = 1 chiffre clé + mini-indicateur · wide = ligne riche · large = chiffre + visualisation (barres / courbe / calendrier / liste). Chaque module remplit sa forme.
  • Le modèle de données ne change pas : ordre + forme par hub, pavage 2 colonnes dérivé (sans migration).
  • À valider avant code : l'interaction DnD (fantôme + barre d'insertion), l'emplacement des pastilles de coin, et le contenu des grands carrés (barres/courbe) module par module.
