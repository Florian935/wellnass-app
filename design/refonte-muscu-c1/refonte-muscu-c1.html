Décisions & portée (rappel spec C1)

  • Disposition : carte « série en cours » (dernière perf + steppers − / +) + liste repliée (aperçu + saut) ; état de fin « Séance terminée ? » quand tout est validé.
  • Gestion des séries en direct (liste dépliable) : + Série / supprimer une série, et dé-valider une série (tap sur la coche, sans relancer le repos) pour corriger une erreur.
  • Valider = enregistre + repos plein écran + avance auto. Pré-remplissage : cible du plan → dernière perf → série précédente. Steppers incrément 2,5 kg (clavier possible).
  • Repos : durée du plan sinon 90 s, plein écran + vibration (RN core) + Passer / +15 s, éditable par exercice (le temps de la séance).
  • Garde-fous : ✕ → Continuer / Pause / Abandonner (2ᵉ confirmation) ; keep-awake ; Terminer avec avertissement si 0 série validée.
  • Fin : résumé rendu éditable — ressenti 5★ + note après coup (via setWorkoutFeedback). Aucune migration (réutilise workouts.rpe/notes).
  • Hors C1 : types de séries / RPE par série / charge planifiée-réalisée → C2 ; réorg / machine prise / superset / remplacer / note par exo / démo / suggestion → C3.
