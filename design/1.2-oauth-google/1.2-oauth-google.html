3 · Après connexion
Nouveau compte → onboarding · compte lié → app
Nouveau compte (e-mail Google inconnu) → session ouverte → gate d'onboarding (comme une inscription e-mail).
E-mail déjà connu (compte e-mail/mdp, e-mail vérifié) → liaison automatique : même compte, données retrouvées, pas de doublon.
Cas limite — e-mail existant non vérifié → liaison refusée → message « vérifie d'abord ton e-mail ».
Annulation (ferme le sélecteur) → retour à l'écran, aucune erreur (no-op).

Notes — Bouton identique sur l'écran d'inscription (même « ou » + mention). Approche native (@react-native-google-signin) → nouveau dev build. Erreurs (Play Services, hors-ligne, liaison) mappées via nos propres clés i18n. Prérequis Client IDs Google (Cloud) + provider Supabase + EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID. Hors périmètre : OAuth Apple (iOS reporté), persistance serveur du consentement, délier un compte, One Tap. Logo Google = illustratif (le composant respectera les guidelines Google).
