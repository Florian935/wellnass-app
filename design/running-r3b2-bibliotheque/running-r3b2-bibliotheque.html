Décisions (rappel)

  • Onglet « Bibliothèque » à côté de « Mes programmes » dans le même écran (patron muscu). Filtres objectif / niveau / durée (combinés).
  • « Utiliser » = duplicateProgram → copie éditable et non active dans « Mes programmes », puis navigation vers son détail (l'utilisateur active/personnalise ensuite).
  • Contenu seedé : 3 programmes « starter » bilingues FR+EN (idempotents, synchronisés via shared_content). Enrichissement curé = tâche contenu ultérieure.
  • Aucune migration de schéma ; niveau = enum beginner/intermediate/advanced (« Régulier » = intermediate). Réutilise useProgramLibrary (filtre pilier ajouté) + duplicateProgram.
  • Polices : stand-ins système ici ; en app = Bricolage / Hanken / Space Mono.
