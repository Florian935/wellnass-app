TRI-03 — Score de forme / readiness global

Widget transverse du dashboard (Tier 0, ADR-007), sur le même modèle que wellbeing/review — pas un widget conditionnel Tier 2 comme META-19/TRI-12 : celui-ci a quelque chose à dire la plupart des jours, pas seulement quand ça va mal.

✅ Décisions D1-D7 arbitrées par Florian le 03/08/2026, code livré (TDD) le même jour — cette maquette reflète la règle R4 telle qu'implémentée (voir §3.1 pour la correction découverte pendant le TDD).

La méthode : 3 composantes, jamais moyennées — le pire signal l'emporte

Pas un indice 0-100 fabriqué (aucune brique de l'app n'en produit) : un verdict à 3 états + un détail toujours traçable jusqu'à sa source, cohérent avec le reste de l'app (zones ACWR, échelle 1-5 avec libellé).

charge = zone ACWR (computeAcwr, déjà posée par META-19/RUN-18)
nutrition = écart à la cible sur les jours loggés (≥ 4/7), seuil DEFICIT_ALERT_RATIO
bien-être = énergie + stress moyens sur 3 jours (daily_wellbeing, BIEN-01)
verdict = « Repos conseillé » si une composante est négative, sinon « Prêt à pousser » si au moins une composante est positive, sinon « Forme correcte »
⚠️ Corrigé pendant le TDD (03/08/2026) : la première version exigeait que toutes les composantes disponibles soient positives pour « Prêt à pousser ». Or la nutrition (règle R2) ne produit jamais l'état positif (pas de symétrie sur le surplus) — avec l'ancienne règle, un utilisateur nutrition active n'aurait jamais pu voir « Prêt à pousser ». Un seul signal positif suffit désormais, symétrique du « un seul négatif suffit ».

3 · MR-23 absorbée, MUSC-23 distincte

MR-23 (« Score de récupération/readiness croisé », muscu+course « sans wearable ») décrivait exactement le cas de gauche ci-dessus sans le bien-être ni la nutrition — la dégradation par composante (D2) couvre déjà ce scénario, MR-23 est donc absorbée par TRI-03 dans le catalogue (même précédent que MR-10 → TRI-12), pas construite séparément. MUSC-23 (tendance du RPE dans le temps, par exercice) reste un candidat distinct : une courbe intra-muscu, pas un verdict transverse du jour.

Les règles qui gouvernent le verdict

R4 — Un seul signal suffit, dans les deux sens Une seule composante négative suffit pour « Repos conseillé », même si les deux autres sont excellentes — jamais compensé. Symétriquement, une seule positive suffit pour « Prêt à pousser » (corrigé pendant le TDD, §3.1) — la nutrition ne produisant jamais l'état positif, exiger que toutes le soient aurait rendu ce verdict inatteignable dès qu'elle est active.
R5 — Aucune composante disponible → widget masqué Pas de verdict par défaut sur une absence totale de données (cas 2 ci-dessus).
D5 — Bien-être : énergie + stress seulement, jamais l'humeur Un check-in où seule l'humeur est renseignée compte comme composante bien-être indisponible, pas neutre.
R8 — Détail toujours traçable Jamais un verdict nu : chaque composante et sa raison d'indisponibilité éventuelle restent consultables dans le détail déplié.
