Décisions & portée (rappel spec C2)

  • Types de séries : Normale / Échauffement / Dropset / Échec / Durée / Poids de corps. 🔥 échauffement en 1 tap (le geste le plus fréquent) sans ouvrir le sélecteur complet. Nouvelles valeurs d'enum dropset/failure.
  • Règle métier : le volume exclut warmup seul ; les records excluent warmup et duration ; bodyweight lesté = record légitime ; dropset/échec comptent partout.
  • Saisie adaptée : duration → mm:ss (reps masqué) ; bodyweight → charge optionnelle (lest).
  • RPE par série (1-10, optionnel) — masqué derrière un « ＋ RPE » discret (peu d'utilisateurs s'en serviront) ; déplié = sélection 1-10. Distinct du ressenti global 5★ de fin de séance (C1). Colonne workout_sets.rpe. Idée notée : proposer le RIR en alternative (préférence profil).
  • Charge planifiée vs réalisée : snapshot planned_weight_kg figé au démarrage ; affichage « Prévu : X » + écart (=/▲/▼) ; survit dans le résumé et l'historique.
  • 🔴 Migration cloud : colonnes rpe + planned_weight_kg, assouplissement du CHECK set_type (workout_sets + exercise_plans). Poussée sur go explicite uniquement.
  • Hors C2 : superset (enchaînement + repos après la paire), réorg, machine prise, remplacer, note par exo, démo, suggestion de progression → C3.
