Pourquoi un tableau, pas une courbe : le catalogue mentionne « courbe charge↔reps » en description, mais déclare le type comme tableau. Une courbe ferait doublon avec la courbe de progression déjà présente sur cette fiche (poids/volume/1RM dans le temps) — ce bloc répond à une question différente (« ma charge selon le nombre de reps », pas « ma charge dans le temps »).

Les règles qui gouvernent l'affichage

R3 — Même éligibilité que les 3 records existants done=1, ni échauffement ni gainage, poids et reps renseignés — pas une règle inventée pour cette US.
R4 — Plage jamais travaillée = absente Jamais une ligne à 0 kg, qui se lirait comme un échec plutôt qu'une absence de donnée.
R5 — Égalité de charge → la plus récente gagne Cohérent avec l'ordre déjà utilisé pour le 1RM réel ailleurs sur cette même fiche.
R6 — Ordre fixe 1 → 12+, jamais par charge Un tableau qui se réordonne à chaque séance serait illisible pour comparer visuellement le spectre.
