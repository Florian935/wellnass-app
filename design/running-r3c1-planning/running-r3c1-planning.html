Décisions (rappel)

  • Semaine type + date de début : à l'activation, l'utilisateur affecte chaque séance-gabarit à un jour de semaine ; l'app génère les instances datées sur toute la durée (durée × séances). Progression auto de volume différée.
  • Vue semaine (7 jours), navigation ‹ / › ; jours de repos affichés ; allures dérivées du profil coureur (R3a) via useUnits (min/km ou min/mi).
  • Séance manquée = date passée encore « planifiée ». Bannière d'agrégation + badge par jour. Actions : Reporter (déplace 1 instance ; options rapides + choix de jour, pas de date-picker natif) ou Sauter. Marquer faite disponible aussi.
  • Marquage manuel au MVP — démarrer une course depuis une séance planifiée (lien tracker) est différé (R4). Les courses libres comptent dans l'historique/streak indépendamment.
  • Table générique planned_sessions (pilier hérité de la séance/programme) : prépare le planning muscu (3.9) et la coordination muscu↔running (5.6, différée).
