2 · Après le jour 7 (ou après « Passer ») — aucun trou dans la grille

Jour 8 : le widget a disparu
— aucun widget ici, le tableau de bord se repacke sans trou —
Point technique déterminant (trouvé en relecture de spec) : rendre le composant null ne suffit pas à éviter une cellule vide dans la grille — deux widgets déjà livrés (training-load, overtraining-guard) ont ce défaut latent aujourd'hui. Ce widget doit être explicitement déclaré dans isWidgetActive ((tabs)/index.tsx), pas seulement rendre null en interne.

Les règles qui gouvernent le parcours

R1 — Fenêtre calendaire stricte Jour = jours écoulés depuis la fin de l'onboarding + 1, borné 1-7. Aucun rattrapage d'un jour manqué.
R2 — Piliers lus en direct Jamais un instantané figé à l'inscription — désactiver un pilier change le contenu du jour immédiatement.
R5 — La coche n'est jamais une porte Le calendrier avance qu'on ait fait l'action suggérée ou pas — c'est un retour visuel, pas un gardien.
R7 — Priorité muscu ＞ running ＞ nutrition Pour les jours pilier-spécifiques, quand plusieurs piliers sont actifs (calcul structurel, jamais lié à ce qui a été fait — spec §2 ter).
