## Tour 2 — 15/09/2026 (page 2 de la toile)

Florian a retenu **E · Les disques**. Le tour 2 les retravaille sans 3D et propose trois concepts
pensés pour la 3D, avec les mêmes leviers et règles.

| Fichier | Concept |
|---|---|
| `Tour2.dc.html` | Compte rendu du tour 2 : ce qui change dans les disques, trois concepts, comparatif, avis |
| `DisquesE2.dc.html` | **E · Les disques v2** — fonte en caoutchouc et acier, piste-stade avec gazon et coureur, assiette compartimentée (saumon, riz, légumes) dont les portions suivent le déficit, anneau des nuits, croisements en médailles |
| `CordeF.dc.html` | **F · La corde** — trois brins tressés (épaisseur = dose), nœuds = croisements, kettlebell = charge ; rompue au garde-fou |
| `SalleG.dc.html` | **G · Ta salle** — pièce isométrique : rack, tapis de course, table, fenêtre de nuit, tapis de récup ; chemins au sol |
| `ChronoH.dc.html` | **H · Le chrono** — chronographe : compteurs séances / km / réserve d'énergie, semaine sur la lunette, trotteuse régulière ou hachée |

Sources générées par les scripts de la session (briques communes : moteur de règles, médailles,
téléphone) ; chaque prototype contrôlé dans Chrome headless en trois états.

**Avis du tour 2** : disques v2 comme système partout ; **Ta salle** pour la scène 3D le moment venu ;
**Le chrono** pour le widget d'accueil.
