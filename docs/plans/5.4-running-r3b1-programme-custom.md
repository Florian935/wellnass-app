## Phase A — `@wellness/shared` : contenu de séance running (TDD)

### Task 1 : types + validation du contenu de séance running

**Files:** MAJ `packages/shared/src/running-paces.ts` (+ `.test.ts`) ; `index.ts` déjà exporté.

- [ ] Ajouter :
```ts
/** Types de séance utilisables dans un programme (course libre exclue). */
export const PROGRAM_SESSION_TYPES = ['endurance','fractionne','sortie_longue','recuperation'] as const;
export type ProgramSessionType = (typeof PROGRAM_SESSION_TYPES)[number];

/** Une séance running a besoin d'au moins une cible (distance en m OU durée en s). */
export function hasRunningSessionTarget(
  targetDistanceM: number | null | undefined,
  targetDurationSeconds: number | null | undefined,
): boolean {
  return (targetDistanceM != null && targetDistanceM > 0)
    || (targetDurationSeconds != null && targetDurationSeconds > 0);
}
```
- [ ] Tests : `PROGRAM_SESSION_TYPES` exclut `course_libre` **et est un sous-ensemble de `SESSION_TYPES`** (`PROGRAM_SESSION_TYPES.every(t => SESSION_TYPES.includes(t))`) ; `hasRunningSessionTarget` (distance seule / durée seule / les deux → true ; aucune / 0 / null → false).

## Phase B — Migration + schéma PowerSync

### Task 2 : `ALTER sessions` (contenu running) + PowerSync

**Files:** Create `supabase/migrations/20260712100000_running_session_content.sql` ; MAJ `apps/mobile/src/powersync/schema.ts`.

- [ ] Migration (additive, rétrocompatible ; **ne touche pas** les séances muscu existantes) :
```sql
alter table public.sessions
  add column session_type text
    check (session_type in ('endurance','fractionne','sortie_longue','recuperation')),
  add column target_distance_m integer,
  add column target_duration_seconds integer;

-- Cible obligatoire uniquement pour les séances running (session_type non nul).
alter table public.sessions
  add constraint sessions_running_target_chk
  check (session_type is null or target_distance_m is not null or target_duration_seconds is not null);
```
(Pas de nouvelle table, pas de sync rule à changer — `sessions` déjà dans `user_data` + `shared_content`.)
- [ ] **Schéma PowerSync local** : ajouter à la déclaration `sessions` (schema.ts) : `session_type: column.text`, `target_distance_m: column.integer`, `target_duration_seconds: column.integer`.
