> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

> **Décisions de conception verrouillées (rappel spec) :**
> - **Jour de semaine : 0 = lundi … 6 = dimanche** (ISO). `Date.getDay()` renvoie 0 = dimanche → conversion `(getDay() + 6) % 7` **partout**.
> - **`scheduled_date` = date calendaire** `AAAA-MM-JJ` (texte), jamais un timestamp. `today = localDayKey(new Date())`.
> - **Re-planifier = idempotent** : soft-delete de **toutes** les instances `planned` du programme (passées comprises), conserve `done`/`skipped`.
> - **`planRunningProgram` = un seul `writeTransaction`** ; l'activation est **inlinée** (on ne peut pas imbriquer `activateProgram`, qui ouvre sa propre transaction).
> - **Convention colonnes : `owner_id`** (comme `programs`/`sessions`), RLS `owner_id = auth.uid()`, bucket `user_data`.
> - **Pas de date picker natif** : sélection de date en JS pur (voir Phase E).

/** Jour de semaine ISO : 0 = lundi … 6 = dimanche (JS getDay() est 0 = dimanche). */
export function weekdayIndex(d: Date): number {
  return (d.getDay() + 6) % 7;
}

/** Nouvelle date décalée de `n` jours (préserve l'heure locale ; usage sur dates calendaires). */
export function addDays(d: Date, n: number): Date {
  const copy = new Date(d);
  copy.setDate(copy.getDate() + n);
  return copy;
}

/** Lundi de la semaine contenant `d` (00:00 local non garanti — n'utiliser que via localDayKey). */
export function startOfWeek(d: Date): Date {
  return addDays(d, -weekdayIndex(d));
}

- [ ] **Step 3 : implémenter** (`planning.ts`) — décision d'alignement : **on aligne la génération sur le lundi de la semaine de `startDate`** (les jours affectés sont relatifs à la semaine, pas à la date exacte saisie) ; comparer les dates comme chaînes `AAAA-MM-JJ` (comparaison lexicographique = chronologique) :
```ts
import { addDays, localDayKey, startOfWeek } from './date';

export type PlannedStatus = 'planned' | 'done' | 'skipped';
export interface PlanTemplateSession { sessionId: string; dayOfWeek: number; } // 0=lundi..6=dimanche
export interface GeneratedPlannedSession { sessionId: string; scheduledDate: string; weekIndex: number; }

export function generatePlannedSessions(input: {
  templateSessions: PlanTemplateSession[];
  startDate: string; // AAAA-MM-JJ
  durationWeeks: number;
}): GeneratedPlannedSession[] {
  const [y, m, d] = input.startDate.split('-').map(Number);
  const weekMonday = startOfWeek(new Date(y!, m! - 1, d!));
  const out: GeneratedPlannedSession[] = [];
  for (let w = 0; w < input.durationWeeks; w++) {
    for (const s of input.templateSessions) {
      const date = addDays(weekMonday, w * 7 + s.dayOfWeek);
      out.push({ sessionId: s.sessionId, scheduledDate: localDayKey(date), weekIndex: w });
    }
  }
  return out;
}

/** Séance passée (date < today) encore au statut `planned`. Dates au format AAAA-MM-JJ. */
export function isMissed(scheduledDate: string, status: PlannedStatus, today: string): boolean {
  return status === 'planned' && scheduledDate < today;
}
```
