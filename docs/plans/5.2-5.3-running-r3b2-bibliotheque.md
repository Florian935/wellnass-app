# Running R3b-ii — Bibliothèque de programmes de course — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Une **bibliothèque de programmes de course** pré-construits (filtrable) + « Utiliser » (duplication dans mes programmes), en réutilisant l'infra bibliothèque muscu.

**Architecture:** Filtre pilier ajouté à `useProgramLibrary(pillar?, filters?)` ; **onglet Bibliothèque** dans `running-programs/index.tsx` (parcours + filtres + « Utiliser » = `duplicateProgram`) ; **2-3 programmes seedés** (bilingues, séances running) dans `seed.sql`. **Aucune migration de schéma.** Offline-first ; **🔴 checkpoint cloud léger** (seed appliqué après R3a + R3b-i).

**Tech Stack:** `apps/mobile` (Expo Router, useUnits, i18next), Supabase `seed.sql`, PowerSync `shared_content`. Réutilise `useProgramLibrary`/`duplicateProgram` + `RUNNER_OBJECTIVES`/`sessionTargetPace` (R3a) + le contenu de séance running (R3b-i).

**Spec :** [5.2-5.3-running-r3b2-bibliotheque.md](../specs/functional/us/5.2-5.3-running-r3b2-bibliotheque.md) (validée). **Patrons :** `useProgramLibrary`/`programs/index.tsx` (onglets biblio muscu), `seed.sql` (section programmes muscu).

**Branche :** `feature/running-r3b2-bibliotheque`, depuis `dev` (spec `f65e5c4`).

## Phase B — Seed : programmes de course « starter »

### Task 2 : contenu bibliothèque running dans `seed.sql`

**Files:** MAJ `supabase/seed.sql`.

READ la section « programmes » muscu du seed pour calquer le format (UUID déterministes, `ON CONFLICT DO NOTHING`, `owner_id null`, `program_translations` FR+EN, `sessions` owner_id null). Ajouter une section « Programmes de course (bibliothèque) » avec **UUID préfixe dédié** (ex. `c1000010…`/`c2000010…`/`c3000010…`) pour ne pas collisionner avec la muscu.

**Contenu à seeder (starter, simple et défendable — cibles en mètres) :**

- [ ] **Programme 1 — `10k` / `beginner` / 8 semaines**
  - FR name « 10 km en 8 semaines », summary « Prépare un premier 10 km avec 3 séances par semaine. » · EN « 10K in 8 weeks » / « Prepare for your first 10K with 3 sessions per week. »
  - Séances (order_index 0..2) : Endurance `session_type='endurance'` `target_distance_m=5000` · Fractionné `fractionne` `target_distance_m=5000` · Sortie longue `sortie_longue` `target_distance_m=8000`.
- [ ] **Programme 2 — `semi` / `intermediate` / 10 semaines**
  - FR « Prépa semi-marathon », « Monte en volume vers le semi avec 4 séances par semaine. » · EN « Half-marathon prep » / « Build up to the half with 4 sessions per week. »
  - Séances : Endurance `8000` · Fractionné `6000` · Sortie longue `16000` · Récupération `recuperation` `target_distance_m=5000`.
- [ ] **Programme 3 — `endurance` / `beginner` / 6 semaines**
  - FR « Reprise en douceur », « Reviens à la course progressivement, sans pression. » · EN « Easy return to running » / « Ease back into running, no pressure. »
  - Séances : Endurance `4000` · Récupération `3000` · Sortie longue `6000`.

Toutes les séances : `owner_id null`, `session_type` renseigné + `target_distance_m` (respecte la check constraint R3b-i), `name` optionnel (peut rester null → l'écran affiche le libellé du type). Idempotent (`ON CONFLICT (id) DO NOTHING`). Ajouter un commentaire « contenu starter, à enrichir (tâche contenu ultérieure) ».
