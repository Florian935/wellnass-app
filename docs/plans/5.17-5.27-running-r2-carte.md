# Running R2 — Carte du parcours — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Afficher le tracé GPS d'une course sur une carte **MapLibre + MapTiler** — en direct pendant la course (5.17) et au résumé (5.27) — avec simplification Douglas-Peucker à l'affichage.

**Architecture:** Helper de simplification **pur** dans `@wellness/shared` (`simplifyTrack`, testé) ; ajout de la dépendance native **`@maplibre/maplibre-react-native`** (config plugin Expo → nouveau dev/preview build) ; un **composant `RouteMap` réutilisable** (live `follow` / résumé `fitBounds`) ; exposition de `gpsTrack` dans `RunDetail` ; branchement des deux écrans running. Aucune migration, tracking inchangé (offline).

**Tech Stack:** `@wellness/shared` (TS pur + Vitest), `apps/mobile` (Expo, `@maplibre/maplibre-react-native` v11, `decodeTrack`/`GpsPoint` existants). MapTiler (clé env, palier gratuit).

**Spec :** [5.17-5.27-running-r2-carte.md](../specs/functional/us/5.17-5.27-running-r2-carte.md) (validée 11/07/2026). **Décision fournisseur :** [ADR-006](../adr/ADR-006-cartographie.md).

**Branche :** `feature/running-r2-carte`, depuis `dev` (spec commitée `22c8085`).

> ⚠️ **Lire la doc versionnée avant de coder le natif** : `apps/mobile/AGENTS.md` impose de lire les docs Expo SDK 57 ; pour MapLibre, lire la doc **`@maplibre/maplibre-react-native` v11** (setup Expo, `MapView`/`Camera`/`ShapeSource`/`LineLayer`, offline non requis ici). ## Phase A — `@wellness/shared` : simplification (TDD)

### Task 1 : `simplifyTrack` (Douglas-Peucker)

**Files:** Create `packages/shared/src/geo.ts` (+ `geo.test.ts`) ; MAJ `index.ts`.

Contrat : `simplifyTrack(points: GpsPoint[], epsilonMeters: number): GpsPoint[]` — Douglas-Peucker, distance perpendiculaire en **mètres** (approximation équirectangulaire : projeter lat/lng en mètres locaux avec `metersPerDegLat ≈ 111320`, `metersPerDegLng ≈ 111320 * cos(latMoyenne)`). **Conserve `.t`** (retourne des `GpsPoint`). Préserve **toujours** le premier et le dernier point.

- [ ] **Tests rouges** (`geo.test.ts`) :
```ts
import { simplifyTrack } from './geo';
import type { GpsPoint } from './running';
const p = (lat: number, lng: number, t: number): GpsPoint => ({ lat, lng, t });

describe('simplifyTrack (Douglas-Peucker)', () => {
  it('trace vide ou 1-2 points → renvoyée telle quelle', () => {
    expect(simplifyTrack([], 5)).toEqual([]);
    const one = [p(48.85, 2.35, 0)];
    expect(simplifyTrack(one, 5)).toEqual(one);
    const two = [p(48.85, 2.35, 0), p(48.86, 2.36, 10)];
    expect(simplifyTrack(two, 5)).toEqual(two);
  });
  it('points quasi-colinéaires → réduits aux 2 extrémités', () => {
    // 3 points sur une même ligne (le milieu à < ε du segment) → milieu supprimé
    const line = [p(48.8500, 2.3500, 0), p(48.8505, 2.3505, 5), p(48.8510, 2.3510, 10)];
    const out = simplifyTrack(line, 5);
    expect(out).toEqual([line[0], line[2]]);
  });
  it('un détour marqué (> ε) est conservé', () => {
    // milieu franchement décalé → conservé
    const detour = [p(48.8500, 2.3500, 0), p(48.8600, 2.3700, 5), p(48.8510, 2.3510, 10)];
    expect(simplifyTrack(detour, 5).length).toBe(3);
  });
  it('ε = 0 → aucune suppression (tous les points conservés)', () => {
    const pts = [p(48.85, 2.35, 0), p(48.851, 2.351, 5), p(48.852, 2.352, 10)];
    expect(simplifyTrack(pts, 0)).toEqual(pts);
  });
  it('conserve toujours les extrémités et l’ordre temporel', () => {
    const pts = Array.from({ length: 20 }, (_, i) => p(48.85 + i * 0.001, 2.35 + i * 0.001, i));
    const out = simplifyTrack(pts, 5);
    expect(out[0]).toEqual(pts[0]);
    expect(out[out.length - 1]).toEqual(pts[pts.length - 1]);
    expect(out.map((x) => x.t)).toEqual([...out.map((x) => x.t)].sort((a, b) => a - b));
  });
});
```
> Ajuster les valeurs numériques attendues au 1ᵉʳ run si l'approximation métrique donne un résultat légèrement différent (sans affaiblir : les extrémités préservées, colinéaire→2 pts, détour→conservé restent les invariants).

- [ ] Vérifier l'échec, implémenter Douglas-Peucker récursif (ou itératif) dans `geo.ts`, vérifier le vert.
- [ ] **Exporter depuis `packages/shared/src/index.ts`** (`export * from './geo';`) — sinon `simplifyTrack` ne sera pas importable côté mobile (erreur seulement au typecheck sinon).
- [ ] `npm run test -w @wellness/shared` + `npm run typecheck -w @wellness/shared` verts.
- [ ] **Commit** : `feat(shared): simplifyTrack (Douglas-Peucker, simplification de trace GPS)`

## Phase D — Composant `RouteMap`

### Task 4 : `RouteMap.tsx` réutilisable

**Files:** Create `apps/mobile/src/components/running/RouteMap.tsx`.

Props : `{ points: GpsPoint[]; follow?: boolean; emptyLabel: string; height?: number }`.
Comportement (contrat des états — sans ambiguïté) :
- `!hasMapKey` (clé MapTiler absente) → bloc neutre affichant `t('running.map.unavailable')` **géré en interne par `RouteMap`** (log dev une fois) ; jamais de crash. Priorité sur les autres états.
- sinon `points.length === 0` → bloc neutre affichant **`emptyLabel`** (prop fournie par l'**écran** : `awaitingGps` pour une course GPS sans point, `noTrack` pour une course manuelle — cf. §2 de la spec). **Ne pas** monter la carte.
- **Hors-ligne (échec de chargement des tuiles)** : au MVP, **pas de détection réseau proactive** ni de message dédié — si `hasMapKey` et `points` non vide, on monte la carte ; si les tuiles ne se chargent pas, la zone reste neutre/partielle **sans bloquer l'écran** (le reste de l'écran fonctionne). (C'est pourquoi il n'y a **pas** de clé `map.offline` séparée au MVP.)
- Sinon (`hasMapKey` et `points.length >= 1`) → monter `MapView` (style `MAP_STYLE_URL`) + `ShapeSource` (LineString des `points` → `[lng, lat]`) + `LineLayer` (couleur `colors.accent`, largeur ~4).
  - `follow` (live) : `Camera` centrée sur le **dernier point** (recentrage à chaque changement de `points`), + un marqueur (`PointAnnotation`/`CircleLayer`) sur le dernier point.
  - sinon (résumé) : `Camera` avec `bounds`/`fitBounds` sur l'enveloppe des points (padding ~40).
- Attribution MapLibre **visible** (activer le logo/attribution du `MapView` ; ne pas la masquer).
- Lire la doc `@maplibre/maplibre-react-native` v11 pour l'API exacte (`MapView`, `Camera`, `ShapeSource`, `LineLayer`, `CircleLayer`/`PointAnnotation`, `setCamera`/`bounds`).

- [ ] Implémenter ; typecheck + lint. **Commit** : `feat(mobile): composant RouteMap (MapLibre, tracé + états vides)`

> **Tests** : pas de test unitaire du composant (module natif). Un smoke jest-expo n'a d'intérêt que si l'on mocke MapLibre — **optionnel**, à ne faire que si trivial. La vérif carte = device (Phase G).
