# Plan d'implémentation — Admin constructeur de programmes éditoriaux (8.4)

> Exécuter avec `superpowers:subagent-driven-development`. Spec validée :
> [docs/specs/functional/us/8.4-admin-constructeur-programmes.md](../specs/functional/us/8.4-admin-constructeur-programmes.md).
> Branche : `feature/admin-8.4-constructeur-programmes`. **🔴 checkpoint cloud** : migration RLS + `db:types` (Florian, projet `nsxzflxsgovriwwvflxe`).

**Objectif :** composer des programmes éditoriaux (muscu + running) depuis l'admin — programme → séances →
(exos muscu | cibles running), bilingue, brouillon/publié, réorganisation glisser-déposer, archivage.

**Architecture :** migration (RLS d'écriture éditoriale, 4 tables, `is_content_editor`) → couche data `programs.ts`
(supabase-js) → composants réutilisables (SortableList @dnd-kit, ExercisePicker) → écran liste + création → écran
édition/composition. **Aucune sync rule, aucun code mobile.** Pattern hérité de 8.2.

## Maquette
**Aucune** (validé) : réutilise le style des écrans admin F1/F2/8.2 (panneaux, tableau, formulaires).

## Décisions de cadrage (validées 13/07/2026)
- **Piliers** : muscu **et** running (builder *pillar-aware* : muscu = exos ; running = cibles distance/durée/type).
- **Réorganisation** : **@dnd-kit** (nouvelle dépendance web `apps/admin`).
- **Nommage séance** : champ libre + bouton « auto A/B/C ».
- **Suppression** : soft-delete (archive), pas de désarchiver au MVP.

### Tâche 2 — Dépendance @dnd-kit + couche data `programs.ts`

**Fichiers :** `apps/admin/package.json` ; `apps/admin/src/data/programs.ts`.

- [ ] Ajouter `@dnd-kit/core`, `@dnd-kit/sortable`, `@dnd-kit/utilities` (versions compatibles React 19) à
  `apps/admin/package.json` ; `npm install` ; vérifier le build admin (`npm --workspace @wellness/admin run build`).
- [ ] `programs.ts` (supabase-js, typé `Database`, réutilise types `@wellness/shared`) :
  - `AdminProgramRow` (row + nom FR/EN dérivés) ; `listEditorialPrograms()` (`owner_id is null`, `deleted_at is null`,
    join `program_translations` fr/en, tri récent → ancien).
  - `getProgram(id)` : programme + 2 traductions + séances (`order_index`) + exos par séance (`order_index`),
    tous `owner_id is null`, non supprimés.
  - `createEditorialProgram(input)` : UUID client, `owner_id NULL`, `status 'draft'`, pilier figé + insert 2 traductions.
  - `updateProgramMeta(id, input)` : `level/goal/duration_weeks` + upsert 2 traductions (fr/en) ; `setStatus(id, status)`
    (`.is('owner_id', null)`) ; `archiveProgram(id)` : soft-delete programme + traductions + séances + exos (cascade).
  - Séances : `addSession(programId, input?)` (nextOrderIndex), `updateSession(id, input)` (nom + champs running),
    `removeSession(id)` (soft-delete + cascade exos), `reorderSessions(programId, orderedIds)` (réécrit `order_index` 0..n).
  - Exos : `addExercisePlan(sessionId, input)` (nextOrderIndex), `updateExercisePlan(id, input)`
    (`set_type/target_sets/target_reps/target_weight_kg/rest_seconds`), `removeExercisePlan(id)`,
    `reorderExercisePlans(sessionId, orderedIds)`.
  - Toutes les écritures éditoriales : `owner_id NULL`, lectures/écritures scopées `.is('owner_id', null)`. Retours
    typés + messages d'erreur FR (surface). UUID client pour toute nouvelle ligne.
- [ ] typecheck/lint verts.
- [ ] **Commit** : `feat(admin): dépendance @dnd-kit + couche data programmes (CRUD + réordonnancement)`.
