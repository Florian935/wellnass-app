# Plan d'implémentation — US 5.33 (export GPX d'une course)

> Exécuter avec `superpowers:subagent-driven-development`. Spec validée :
> [docs/specs/functional/us/5.33-export-gpx.md](../specs/functional/us/5.33-export-gpx.md).
> Branche : `feature/5.33-export-gpx`.

**Objectif :** exporter la trace d'une course GPS terminée en `.gpx` (GPX 1.1, sans altitude) et l'ouvrir
dans la feuille de partage OS. **100 % local, aucune migration/cloud.** Nécessite `expo-sharing` +
`expo-file-system` → **nouveau build** pour la recette.

**Architecture :** logique pure dans `@wellness/shared` (`isValidCoord`, `buildGpx`, `gpxFileName`, testée) +
fine couche native mobile (`lib/gpx-export.ts`) + bouton conditionnel sur `run/summary.tsx` + i18n FR/EN.

## Maquette

**Pas de maquette dédiée** : ajout mineur d'un **bouton** (« Exporter (GPX) ») sur un écran existant
(`run/summary.tsx`), sous la carte, dans le style de bouton existant (charte). Précédents sans maquette :
US 1.15, US 4.7. Justification à valider avec la spec/plan.
