# US 8.6 — Import aliments CSV (CIQUAL) — Plan d'implémentation

> **Pour l'exécutant :** tâche par tâche (cases `- [ ]`), TDD, commits fréquents.
> Spec : [8.6-import-csv-ciqual.md](../specs/functional/us/8.6-import-csv-ciqual.md).

**Goal :** un écran admin qui importe un CSV formaté d'aliments éditoriaux (FR/EN + macros +
micros), avec aperçu/validation, upsert idempotent (`import_key`) et rapport.

**Architecture :** logique pure de parsing/validation/mapping dans `@wellness/shared/food-csv.ts`
(testée Vitest) ; l'admin (`apps/admin`) fait l'I/O — papaparse (texte→lignes), écran d'aperçu,
`data/foods.ts` (upsert Supabase). Contenu éditorial = `owner_id NULL`, `source 'library'`.

**Tech Stack :** TypeScript, Zod (`@wellness/shared`), React + Vite + react-router (admin),
supabase-js, papaparse, Vitest.

## Task 1 : `@wellness/shared/food-csv.ts` (TDD)

**Files:** Create `packages/shared/src/food-csv.ts` + `food-csv.test.ts` ; Modify `index.ts`.

Interface :
```ts
export type FoodImportRecord = {
  importKey: string; nameFr: string; nameEn: string; category: FoodCategory;
  kcalPer100g: number;
  proteinPer100g: number | null; carbsPer100g: number | null; sugarsPer100g: number | null;
  fatPer100g: number | null; saturatedFatPer100g: number | null; fiberPer100g: number | null;
  micronutrients: Micronutrients;
};
export type FoodCsvRowError = { rowIndex: number; field: string; reason: string };
export type FoodCsvResult = { valid: FoodImportRecord[]; errors: FoodCsvRowError[] };
export function parseFoodCsv(rows: Record<string, string>[]): FoodCsvResult;
```
Règles : `rowIndex` = numéro de ligne de données (1-based, hors en-tête). Requis non vides :
`import_key`, `name_fr`, `name_en`, `category` (∈ `FOOD_CATEGORIES`), `kcal_per_100g` (nombre ≥0).
Macros optionnelles (vide→null ; sinon nombre ≥0). Micros optionnels (clés = `MICRONUTRIENT_KEYS` ;
vide→absent ; sinon nombre ≥0) → validés via `micronutrientsSchema`. **`import_key` dupliqué dans
le fichier** → erreur sur **chaque** ligne concernée. Une ligne avec ≥1 erreur n'est pas dans `valid`.

import { describe, expect, it } from 'vitest';
import { parseFoodCsv } from './food-csv';

const base = { import_key: 'CIQUAL_1', name_fr: 'Pomme', name_en: 'Apple', category: 'fruits', kcal_per_100g: '52' };

describe('parseFoodCsv', () => {

    expect(r.valid[0]).toMatchObject({

    });
  });
  it('cellule optionnelle vide → null / micro absent', () => {
    const r = parseFoodCsv([{ ...base, protein_per_100g: '', sodium_mg: '' }]);
    expect(r.valid[0].proteinPer100g).toBeNull();
    expect(r.valid[0].micronutrients).toEqual({});

  it('catégorie inconnue → erreur', () => {
    const r = parseFoodCsv([{ ...base, category: 'zzz' }]);

    expect(parseFoodCsv([{ ...base, kcal_per_100g: '' }]).errors[0].field).toBe('kcal_per_100g');

    expect(parseFoodCsv([{ ...base, name_en: '' }]).errors[0].field).toBe('name_en');
  });
  it('import_key dupliqué dans le fichier → erreur sur les 2 lignes', () => {
    const r = parseFoodCsv([base, { ...base, name_fr: 'Pomme 2' }]);
    expect(r.valid).toHaveLength(0);
    expect(r.errors.filter((e) => e.field === 'import_key')).toHaveLength(2);

```sql
-- US 8.6 — clé d'import stable pour l'upsert idempotent des aliments éditoriaux (CIQUAL).
alter table public.foods add column if not exists import_key text;
-- Index unique SIMPLE : les NULL (OFF/custom) restent illimités ; seules les clés non nulles
-- (éditorial importé) sont uniques. Nécessaire pour `on conflict (import_key)` de l'upsert
-- (un index PARTIEL ne peut pas servir d'arbitre ON CONFLICT via supabase-js).
create unique index if not exists foods_import_key_key on public.foods (import_key);
```

```ts
import { supabase } from '../lib/supabase';
import { type FoodImportRecord, MICRONUTRIENT_KEYS } from '@wellness/shared';

export type ImportResult = { created: number; updated: number };

const CSV_COLUMNS = [
  'import_key','name_fr','name_en','category','kcal_per_100g',
  'protein_per_100g','carbs_per_100g','sugars_per_100g','fat_per_100g',
  'saturated_fat_per_100g','fiber_per_100g', ...MICRONUTRIENT_KEYS,
];

/** Modèle CSV : en-têtes + 1 ligne d'exemple. */
export function buildCsvTemplate(): string {
  const example = { import_key: 'CIQUAL_13000', name_fr: 'Pomme crue', name_en: 'Raw apple',
    category: 'fruits', kcal_per_100g: '52', protein_per_100g: '0.3', sodium_mg: '1', vitamin_c_mg: '4.6' };
  const line = CSV_COLUMNS.map((c) => (example as Record<string,string>)[c] ?? '').join(',');
  return CSV_COLUMNS.join(',') + '\n' + line + '\n';
}

export async function importFoods(records: FoodImportRecord[]): Promise<ImportResult> {
  const keys = records.map((r) => r.importKey);
  // created vs updated : quelles clés existent déjà (éditorial) ?
  const { data: existing } = await supabase
    .from('foods').select('import_key').in('import_key', keys).is('owner_id', null);
  const known = new Set((existing ?? []).map((r) => r.import_key));

  const foodRows = records.map((r) => ({
    id: crypto.randomUUID(), owner_id: null, source: 'library', import_key: r.importKey,
    category: r.category, kcal_per_100g: r.kcalPer100g,
    protein_per_100g: r.proteinPer100g, carbs_per_100g: r.carbsPer100g, sugars_per_100g: r.sugarsPer100g,
    fat_per_100g: r.fatPer100g, saturated_fat_per_100g: r.saturatedFatPer100g, fiber_per_100g: r.fiberPer100g,
    micronutrients: r.micronutrients, portions: [],
  }));
  const { data: upserted, error } = await supabase
    .from('foods').upsert(foodRows, { onConflict: 'import_key' }).select('id, import_key');
  if (error) throw error;

  const idByKey = new Map((upserted ?? []).map((r) => [r.import_key as string, r.id as string]));
  const translationRows = records.flatMap((r) => {
    const foodId = idByKey.get(r.importKey)!;
    return [
      { id: crypto.randomUUID(), food_id: foodId, owner_id: null, lang: 'fr', name: r.nameFr },
      { id: crypto.randomUUID(), food_id: foodId, owner_id: null, lang: 'en', name: r.nameEn },
    ];
  });
  const { error: tErr } = await supabase
    .from('food_translations').upsert(translationRows, { onConflict: 'food_id,lang' });
  if (tErr) throw tErr;

  let created = 0, updated = 0;
  for (const k of new Set(keys)) (known.has(k) ? updated++ : created++);
  return { created, updated };
}
```

> ce n'est pas fait, un cast local peut être nécessaire — préférer attendre le checkpoint pour le typage.
