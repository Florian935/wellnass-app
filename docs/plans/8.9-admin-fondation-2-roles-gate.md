### Tâche 1 — Migration `user_roles` + fonctions + RLS (SQL) + types

**Fichier :** `supabase/migrations/20260713100000_admin_user_roles.sql` (+ `packages/shared/src/database.types.ts`).

- [ ] **Table** :
  ```sql
  create table public.user_roles (
    id uuid primary key default gen_random_uuid(),
    user_id uuid not null references auth.users(id) on delete cascade,
    role text not null check (role in ('super_admin','content_editor','moderator')),
    created_at timestamptz not null default now(),
    updated_at timestamptz not null default now(),
    deleted_at timestamptz
  );
  create unique index user_roles_user_role_uidx on public.user_roles (user_id, role) where deleted_at is null;
  create trigger set_updated_at before update on public.user_roles
    for each row execute function public.set_updated_at();
  ```
- [ ] **Fonctions** (⚠️ `SECURITY DEFINER STABLE SET search_path = public`) :
  ```sql
  create or replace function public.is_admin() returns boolean
    language sql stable security definer set search_path = public as $$
    select exists (select 1 from public.user_roles where user_id = auth.uid() and deleted_at is null); $$;
  create or replace function public.is_super_admin() returns boolean
    language sql stable security definer set search_path = public as $$
    select exists (select 1 from public.user_roles where user_id = auth.uid() and role = 'super_admin' and deleted_at is null); $$;
  ```
- [ ] **RLS** :
  ```sql
  alter table public.user_roles enable row level security;
  create policy user_roles_select on public.user_roles for select
    using (user_id = auth.uid() or public.is_super_admin());
  create policy user_roles_insert on public.user_roles for insert with check (public.is_super_admin());
  create policy user_roles_update on public.user_roles for update
    using (public.is_super_admin()) with check (public.is_super_admin());
  create policy user_roles_delete on public.user_roles for delete using (public.is_super_admin());
  ```
  **NE PAS** ajouter à la publication `powersync` (table admin/web only).
- [ ] **`database.types.ts`** : ajouter **manuellement** l'entrée `user_roles` (Row/Insert/Update) **conforme au
  schéma ci-dessus**, pour que `supabase.from('user_roles')` typé compile **avant** l'apply cloud. Le futur
  `npm run db:types` (par Florian) régénérera à l'identique (idempotent).
- [ ] typecheck vert (racine).
- [ ] **Commit** : `feat(admin): migration user_roles + is_admin/is_super_admin + RLS`.

### Tâche 2 — Couche data rôles (`apps/admin/src/data/roles.ts`)

- [ ] `AdminRole` = `'super_admin' | 'content_editor' | 'moderator'` (union locale).
- [ ] `fetchMyRoles(userId): Promise<{ roles: AdminRole[]; error: unknown }>` — `select('role').eq('user_id', userId)`
  `is('deleted_at', null)` ; en cas d'erreur (table absente / réseau) → `{ roles: [], error }`.
- [ ] `listRoles()` — `select('*').is('deleted_at', null).order('created_at')` (super_admin voit tout via RLS).
- [ ] `grantRole(userId, role)` — **UPSERT** : `.upsert({ user_id, role, deleted_at: null }, { onConflict: 'user_id,role' })`
  (ré-active un rôle soft-deleted ; l'index partiel gère l'unicité). *(Si `onConflict` sur index partiel pose souci
  côté supabase-js, faire `update deleted_at=null` puis `insert` si aucune ligne — documenter le choix.)*
- [ ] `revokeRole(id)` — `.update({ deleted_at: new Date().toISOString() }).eq('id', id)`.
- [ ] typecheck/lint verts.
- [ ] **Commit** : `feat(admin): couche data des rôles (list/grant/revoke)`.

### Tâche 3 — Contexte rôles + `RequireAdmin` + Accès refusé

- [ ] `RolesProvider`/`useRoles()` : après session (via `useAuth`), `fetchMyRoles(user.id)` → expose
  `{ roles, isAdmin, isSuperAdmin, rolesLoading, rolesError }`. Recharge quand l'utilisateur change. Erreur → non-admin.
- [ ] `RequireAdmin` : `rolesLoading` → spinner ; `isAdmin` → `<Outlet/>` ; sinon → `<AccessDenied/>` (pas de redirection
  vers /login, l'utilisateur EST connecté). Idempotent, hooks inconditionnels.
- [ ] `AccessDenied` : message FR (`fr.accessDenied.*`) + bouton **Déconnexion** (`useAuth().signOut`).
- [ ] typecheck/lint verts.
- [ ] **Commit** : `feat(admin): contexte rôles + gate RequireAdmin + écran Accès refusé`.
