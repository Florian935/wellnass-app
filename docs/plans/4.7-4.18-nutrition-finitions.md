# US 4.7 + 4.18 — Finitions Nutrition — Plan d'implémentation

**Goal:** Brancher deux fonctions déjà écrites mais inaccessibles : appliquer le **bonus calorique
des jours d'entraînement** (4.7, muscu OU running terminé ce jour) et exposer la **duplication d'une
journée** de journal (4.18). 100 % client, aucune migration, aucune nouvelle dépendance.

**Architecture:** La logique pure existe déjà — `trainingDayCalories(target, bonus)` et
`duplicateDay(from, to)`. Le seul nouvel élément data est un hook réactif `useIsTrainingDay(dayKey)`
qui borne une requête `useQuery` sur `[minuit local, +1j[` (UTC) des tables `workouts` et `runs`
(`status='completed'`, `deleted_at IS NULL`). L'objectif effectif est calculé côté écran (journal)
et côté `useNutritionSummary` (dashboard). L'UI ajoute : un champ bonus (profil), un badge (journal +
widget), un bouton copier (journal, jour vide).

**Spec :** [4.7-4.18-nutrition-finitions.md](../specs/functional/us/4.7-4.18-nutrition-finitions.md)
**Patterns à copier :** `useNutritionSummary` (composition de hooks + calcul objectif), `copyMeal`
(bouton + `Alert` « rien à copier »), champ `manualCalories` du profil (TextField numérique).

**Branche :** `feature/nutrition-finitions-4.7-4.18`, depuis `origin/dev` (créée).

**Design :** pas de maquette Claude Design — changements d'UI **mineurs** (un champ, un badge, un
bouton), précédent US 1.15. À confirmer par Damien à la validation.

## Tâches

### 4.7 — Calories jour d'entraînement

- [ ] **Hook `useIsTrainingDay(dayKey: string): boolean`** dans
  [dashboard-repository.ts](../../apps/mobile/src/data/repositories/dashboard-repository.ts).
  Bornes UTC via `new Date(dayKey + 'T00:00:00').toISOString()` (+1 jour). Deux `useQuery`
  (`workouts`, `runs`) `... WHERE status='completed' AND deleted_at IS NULL AND finished_at >= ?
  AND finished_at < ? LIMIT 1`. Retourne `w.length + r.length > 0`.
- [ ] **`useNutritionSummary`** : intégrer `useIsTrainingDay(today)` + `trainingDayBonus` du profil ;
  exposer `isTrainingDay: boolean` et `bonus: number` ; **le `target` retourné reste l'objectif de
  base** (les macros en dépendent), on ajoute `effectiveTarget = trainingDayCalories(target, bonus)`
  appliqué uniquement quand `isTrainingDay && bonus>0`. Mettre à jour la NOTE MVP du type.
- [ ] **Widget** [NutritionSummaryCard.tsx](../../apps/mobile/src/components/dashboard/NutritionSummaryCard.tsx) :
  afficher `effectiveTarget` dans la ligne calories + badge « +X kcal » si `isTrainingDay`.
- [ ] **Journal** [(tabs)/nutrition.tsx](<../../apps/mobile/src/app/(tabs)/nutrition.tsx>) :
  `isTraining = useIsTrainingDay(day)` ; `effectiveTarget` ; utiliser pour la ligne objectif + le
  `remaining`. **Macros inchangées** (base). Badge sous la ligne calories.
- [ ] **Profil** [nutrition-profile.tsx](../../apps/mobile/src/app/nutrition-profile.tsx) : champ
  « Bonus jour d'entraînement (kcal) » dans le bloc calories, `keyboardType="number-pad"`,
  parse entier ≥ 0 (`0`/vide → `0`), `upsertNutritionProfile({ trainingDayBonus })`.
- [ ] **i18n** FR/EN : `journal.trainingDayBadge` (`+{{kcal}} kcal · jour de séance`),
  `nutrition.calories.trainingBonus` (label + hint), `home.nutrition.trainingDayBadge`.

### 4.18 — Copier une journée
