## 2. Comportement attendu

Écran **« Profil nutritionnel »** (modale, accessible depuis l'onglet Nutrition et les Réglages) :

1. **Objectif nutritionnel** (§2.1) : masse / sèche / maintien / perte progressive. Distinct de l'objectif d'entraînement (`main_goal`) ; pré-rempli d'après lui à défaut, puis indépendant.
2. **Facteur d'activité** (§2.2, 5 niveaux) : sédentaire ×1,2 … extrêmement actif ×1,9.
3. **TDEE calculé** (Mifflin-St Jeor × facteur), lecture seule, recalculé en direct depuis poids/taille/âge/sexe du profil.
4. **Objectif calorique** : TDEE + delta d'objectif ; **surcharge manuelle** libre + bouton « recalculer ».
5. **Macros** : répartition par défaut selon l'objectif (§2.3), éditable en **grammes**, % dérivés affichés (les grammes priment, §8).
6. **Restrictions** (§2.4) : 6 cases + allergènes en liste libre.

## 3. Règles métier

- **TDEE indisponible** si poids/taille/âge manquant → état « complète ton profil » + CTA (spec §8).
- **Sexe non précisé** → BMR = moyenne des formules homme/femme.
- **Grammes priment** sur les % (spec §8) : éditer un gramme passe en mode manuel (les 3 grammes stockés ensemble) ; « réinitialiser » repasse aux macros dérivées.
- Deltas d'objectif : masse **+300**, sèche **−400**, maintien **0**, perte progressive **−250** kcal/j.
- Ratios par défaut : masse 30/45/25 · sèche & perte progressive 40/35/25 · maintien 25/50/25.

## 4. Architecture (pattern repository US1)

- **`packages/shared/src/nutrition.ts`** : calculs purs (TDEE, macros, conversions) **+ `nutritionProfileRowSchema`** (Zod, champs de synchro + objectif/activité/macros manuelles/restrictions/allergènes/bonus).
- **Table `nutrition_profiles`** (une ligne par compte) : schéma PowerSync local + migration Supabase + RLS + sync rules (bucket `user_data`).
- **`data/repositories/nutrition-repository.ts`** : `useNutritionProfile()` (lecture réactive `useQuery`) + `upsertNutritionProfile()` (écriture via `_sql`, mapping snake↔camel, JSON pour restrictions/allergènes). Aucun store Zustand.
- **Écrans** : `nutrition-profile.tsx`, carte résumé `(tabs)/nutrition.tsx`, entrée Réglages, route modale `_layout.tsx`.
