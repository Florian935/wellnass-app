## 2. Architecture

- **`packages/shared/src/food.ts`** : enums (catégories, sources, repas), `foodRowSchema`, `foodTranslationRowSchema`, `foodEntryRowSchema`, portions ; helpers purs `resolveFoodName`, `scaleNutrition`, `sumNutrients`. **+ tests**.
- **Tables PowerSync** : `foods` (owner_id null = bibliothèque), `food_translations`, `food_favorites` (user), `food_entries` (user, snapshot). Migrations `20260706150000/150001` + RLS + sync rules edition 3 + **seed 50 aliments**.
- **`food-repository`** : `useFoods(search)`, `useFavoriteFoods`, `addCustomFood`, `importOpenFoodFactsFood`, `toggleFoodFavorite` (nom résolu en SQL, langue → fr).
- **`journal-repository`** : `useDayEntries(date)`, `addFoodEntry`, `updateEntry`, `removeEntry`.
- **`lib/openfoodfacts.ts`** : recherche texte OFF, normalisation.
- **Écrans** : onglet **Nutrition** = journal (nav jours, totaux/macros, 4 repas) ; **food-picker** (recherche locale + OFF, favoris, portions/quantité, quick add) ; **food-custom** (aliment perso).

## 3. Règles & offline

- Entrées = **snapshot** des valeurs (pas de recalcul rétroactif, spec §8).
- 100 % offline sauf la **recherche OpenFoodFacts** (réseau requis, dégradation gracieuse → liste vide).
- FR + EN, enums non traduits (dictionnaire UI). Aliments perso non traduits (langue de saisie).
