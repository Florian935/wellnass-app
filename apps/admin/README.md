# @wellness/admin

**Back-office web d'administration** — gestion de contenu (exercices, programmes, aliments),
rôles à moindre privilège (`super_admin` / `content_editor` / `moderator`), log d'audit
immuable. Servi sur un sous-domaine `admin.*`.
